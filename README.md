# Faith's Kitchen

Luxury comfort food landing page with a working cart, feedback form, and premium styling.

## Highlights
- Premium hero and menu layout with gold + champagne theme.
- Interactive cart with quantity controls, remove, and checkout confirmation.
- WhatsApp and Email order links auto-update from the cart.
- Feedback form via Formspree and star rating.
- Social sharing metadata and SEO basics.

## Live URL
https://wachirafaith335-sudo.github.io/Faith-s-Kitchen/

## Tech Stack
- HTML, CSS, JavaScript (vanilla)

## File Structure
- index.html
- style.css
- script.js
- sitemap.xml
- robots.txt
- og-image.svg
- favicon.svg
- Images: *.jpg, *.webp, *.jfif

## Local Run
Open index.html in a browser.

## Customization
1. Menu items: edit menuItems in script.js.
2. Brand colors: edit CSS variables in :root in style.css.
3. Contact links: update phone/email in index.html.
4. Formspree: replace the form action URL in index.html.

## Deployment (GitHub Pages)
1. Push to GitHub.
2. Settings -> Pages -> Deploy from branch, select main and /root.
3. Wait 1-3 minutes, then open the site URL.
